## 2025-10-24 - Filesystem Display XSS Vulnerability
**Vulnerability:** XSS in `FilesystemDisplay` class where device names and paths were embedded directly into HTML `onclick` attributes and element content without sufficient escaping. Specifically, `readDevices` did not escape `block.label` before passing it to `render`, allowing a malicious USB device label to break out of the `onclick` attribute or inject HTML.
**Learning:** `window._escapeHtml` was used in some places (like `readFS`) but missed in `readDevices`. Additionally, placing strings into `onclick` attributes requires both HTML attribute escaping AND JavaScript string escaping if the value is used as a JS string. `_escapeHtml` alone is insufficient for values inside JS strings within HTML attributes (e.g. `onclick="alert('...')"`).
**Prevention:** Always escape data before embedding it in HTML or JS. Used `window._escapeHtml` for HTML content and introduced `window._escapeStringForJS` for safely embedding strings into JavaScript code blocks. Prefer `addEventListener` over inline `onclick` attributes to avoid this complexity entirely.
